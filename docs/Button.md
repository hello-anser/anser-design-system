# Button

Push button in four weights. The brand law: **amber is a scalpel** — one `primary` button per screen, on the single action that matters most. Everything else is `neutral` (navy), `ghost`, or `danger`.

```tsx
<Button variant="primary">Start demo</Button>
<Button variant="neutral">Save changes</Button>
<Button variant="ghost">Cancel</Button>
<Button variant="danger">Delete number</Button>
```

Sizes: `md` (default) and `sm` for toolbars and table rows. `icon` takes a leading glyph. All native `<button>` props pass through (`onClick`, `disabled`, `type`, …).
