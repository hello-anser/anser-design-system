# SidebarSection

A labelled group of `SidebarItem`s inside a `Sidebar`. The label renders in the instrument-marking idiom (mono, 10px, letter-spaced uppercase) — quiet structure, not decoration.

```tsx
<SidebarSection label="Main">
  <SidebarItem active>Home</SidebarItem>
  <SidebarItem>Call Log</SidebarItem>
</SidebarSection>
<SidebarSection label="Build the agent">
  <SidebarItem>Assistant</SidebarItem>
  <SidebarItem>Knowledge Base</SidebarItem>
</SidebarSection>
```
